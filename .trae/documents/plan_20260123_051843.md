# 将 requests 替换为 httpx 异步网络请求库

## 1. 添加依赖

在 `pyproject.toml` 中添加 `httpx>=0.28.0`

## 2. 替换 tcb_storages.py

将 `tcb_storages.py` 中的同步 requests 替换为异步 httpx：

- `tcb_base_storages_signin()` - 使用 `httpx.AsyncClient().post()`
- `tcb_base_storages_refresh_token()` - 使用 `httpx.AsyncClient().post()`
- 添加详细的中文注释

## 3. 替换 aitryon_tool.py

将 `aitryon_tool.py` 中的同步 requests 替换为异步 httpx：

- `use_aitryon()` - 使用 `httpx.AsyncClient().post()`
- `_query_task_status_sync()` - 重命名为 `_query_task_status_async()`，使用 `httpx.AsyncClient().get()`
- 调整轮询逻辑使用 `asyncio.sleep()` 替代 `time.sleep()`
- 添加详细的中文注释

## 4. 移除 requests 依赖

从 `pyproject.toml` 中移除 `requests`（如果存在）

## 技术优势

- ✅ 完全异步，与 FastAPI 架构完美契合
- ✅ API 设计类似 requests，迁移成本低
- ✅ 支持 HTTP/2，性能更优
- ✅ 内置连接池管理
- ✅ 更好的类型提示和 IDE 支持
