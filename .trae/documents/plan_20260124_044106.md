# 微信授权登录功能实现计划

## 1. 数据库模型扩展 (app/models/user_model.py)

添加微信相关字段：
- `wechat_openid` - 微信 OpenID（唯一）
- `wechat_unionid` - 微信 UnionID（跨应用唯一）
- `wechat_nickname` - 微信昵称
- `wechat_avatar` - 微信头像
- `login_type` - 登录类型（password/wechat）

## 2. 配置文件扩展 (app/mode/config/config.py)

添加微信相关配置：
- `WECHAT_APP_ID` - 微信 AppID
- `WECHAT_APP_SECRET` - 微信 AppSecret
- `WECHAT_REDIRECT_URI` - 微信授权回调地址

## 3. 微信工具模块 (app/utils/wechat_utils.py)

创建微信授权登录工具函数：
- `get_wechat_auth_url()` - 生成微信授权 URL
- `get_wechat_access_token(code)` - 使用 code 换取 access_token
- `get_wechat_user_info(access_token, openid)` - 获取微信用户信息
- `create_or_update_wechat_user()` - 创建或更新微信用户

## 4. 服务层扩展 (app/service/user/user_service.py)

添加微信授权登录服务函数：
- `get_user_by_wechat_openid()` - 根据 OpenID 查询用户
- `create_wechat_user()` - 创建微信用户
- `update_wechat_user_info()` - 更新微信用户信息

## 5. 控制器层扩展 (app/controller/api_v1/user.py)

添加微信授权登录接口：
- `GET /auth/wechat/auth` - 获取微信授权 URL
- `GET /auth/wechat/callback` - 微信授权回调
- `POST /auth/wechat/login` - 微信登录（前端调用）

## 6. 响应模型扩展 (app/models/response_models.py)

添加微信相关响应模型：
- `WechatAuthResponse` - 微信授权响应
- `WechatLoginResponse` - 微信登录响应

## 7. 请求模型扩展 (app/controller/api_v1/user.py)

添加微信相关请求模型：
- `WechatCallbackRequest` - 微信回调请求
- `WechatLoginRequest` - 微信登录请求

## 微信授权登录流程

### 流程说明

1. **前端发起授权**
   - 前端调用 `GET /api/v1/auth/wechat/auth`
   - 后端返回微信授权 URL
   - 前端跳转到微信授权页面

2. **用户授权**
   - 用户在微信页面点击"授权"
   - 微信重定向到回调地址，带上 `code` 参数

3. **后端处理回调**
   - 后端接收 `code` 参数
   - 后端使用 `code` 换取 `access_token` 和 `openid`
   - 后端使用 `access_token` 获取用户信息
   - 后端根据 `openid` 查找或创建用户
   - 后端生成 JWT token
   - 后端返回 token 和用户信息

4. **前端登录成功**
   - 前端接收 token 和用户信息
   - 前端存储 token
   - 前端跳转到首页

### API 接口列表

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|--------|
| GET | `/api/v1/auth/wechat/auth` | 获取微信授权 URL | 无 |
| GET | `/api/v1/auth/wechat/callback` | 微信授权回调 | 无 |
| POST | `/api/v1/auth/wechat/login` | 微信登录（前端调用） | 无 |

### 数据库变更

```sql

ALTER TABLE users ADD COLUMN wechat_unionid VARCHAR(100) COMMENT '微信UnionID';
ALTER TABLE users ADD COLUMN wechat_nickname VARCHAR(100) COMMENT '微信昵称';
ALTER TABLE users ADD COLUMN wechat_avatar VARCHAR(255) COMMENT '微信头像';
ALTER TABLE users ADD COLUMN login_type VARCHAR(20) DEFAULT 'password' COMMENT '登录类型';
```

### 环境变量配置

```env
WECHAT_APP_ID=your_wechat_app_id
WECHAT_APP_SECRET=your_wechat_app_secret
WECHAT_REDIRECT_URI=http://your-domain.com/api/v1/auth/wechat/callback
```

### 注意事项

1. 微信授权 URL 需要在微信开放平台配置
2. 回调地址需要与微信开放平台配置一致
3. 微信 OpenID 是用户在当前应用下的唯一标识
4. 微信 UnionID 是用户在同一开放平台下的唯一标识
5. 支持密码登录和微信登录两种方式
6. 微信用户首次登录时自动创建账号
