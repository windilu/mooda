# MySQL 数据库对接实现计划

## 1. 添加依赖包

在 `pyproject.toml` 中添加：

* `sqlalchemy>=2.0.0` (ORM 核心)

* `aiomysql>=0.2.0` (异步 MySQL 驱动)

## 2. 创建 MySQL 配置

在 `app/mode/config/config.py` 中添加 MySQL 连接配置：

* 数据库地址: 127.0.0.1

* 端口: 3306

* 密码: xiaofeng71

* 支持环境变量配置

## 3. 创建 MySQL 工具类

在 `app/utils/mysql_utils/` 目录下创建：

### 3.1 `__init__.py`

导出 MySQL 客户端单例

### 3.2 `mysql_client.py`

实现 `MySQLClient` 类，参考 Redis 的封装风格：

* `initialize()` - 初始化连接池

* `close()` - 关闭连接

* `get_session()` - 获取异步会话

* `execute_query()` - 执行原生 SQL 查询

* `execute_update()` - 执行更新/插入/删除

* `transaction()` - 事务管理

### 3.3 `base_model.py`

创建 SQLAlchemy 基础模型类，供其他模型继承

## 4. 集成到 FastAPI 生命周期

在 `main.py` 的 `lifespan` 中：

* 启动时初始化 MySQL 连接池

* 关闭时释放 MySQL 资源

## 5. 创建使用示例

创建示例代码展示如何使用 MySQL 工具类

## 技术特点

* ✅ 异步连接池管理

* ✅ 支持 ORM 和原生 SQL

* ✅ 事务支持
