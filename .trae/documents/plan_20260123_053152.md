# 使用主流库实现登录验证功能

## 1. 添加依赖包

在 `pyproject.toml` 中添加主流认证库：
- `fastapi-users[sqlalchemy]>=13.0.0` - FastAPI 用户认证主流库，内置 JWT、密码加密、用户管理
- `alembic>=1.13.0` - 数据库迁移工具，管理表结构变更
- `asyncmy>=0.2.9` - MySQL 异步驱动（比 aiomysql 更稳定）

## 2. 创建用户模型

在 `app/models/` 目录下创建 `user_model.py`：
- 继承 fastapi-users 的 BaseUser 模型
- 自定义字段：phone, nickname, avatar
- 自动获得：id, username, email, password（已加密）等基础字段

## 3. 配置 FastAPI-Users

在 `app/utils/` 目录下创建 `auth_config.py`：
- 配置数据库连接
- 配置 JWT secret 和过期时间
- 配置用户模型

## 4. 创建用户服务层

在 `app/service/user/` 目录下创建 `user_service.py`：
- 使用 fastapi-users 的 UserManager
- 封装用户 CRUD 操作
- 所有操作都是异步的

## 5. 创建用户控制器

在 `app/controller/api_v1/` 目录下创建 `user.py`：
- `POST /register` - 用户注册（无需 token）
- `POST /auth/jwt/login` - 用户登录（无需 token，返回 JWT）
- `GET /users/me` - 获取当前用户信息（需要 token）
- `GET /users/{id}` - 根据 ID 查询用户（需要 token）
- `GET /users` - 查询用户列表（需要 token）
- `PUT /users/me` - 更新当前用户信息（需要 token）
- `DELETE /users/me` - 删除当前用户（需要 token）

## 6. 配置 Alembic 数据库迁移

在项目根目录创建 `alembic.ini`：
- 配置数据库连接
- 配置迁移脚本路径

## 7. 创建数据库迁移脚本

在 `alembic/versions/` 目录下：
- 创建初始迁移脚本
- 自动创建 mooda 数据库和用户表

## 8. 集成到 FastAPI

在 `main.py` 中：
- 初始化 fastapi-users 认证路由
- 添加用户路由到 API v1

## 技术优势

- ✅ **fastapi-users** - FastAPI 生态最主流的用户认证库，功能完整
- ✅ **Alembic** - SQLAlchemy 官方推荐的数据库迁移工具
- ✅ **无需造轮子** - JWT、密码加密、token 验证全部内置
- ✅ **异步支持** - 完全异步，与 FastAPI 完美契合
- ✅ **生产级** - 经过大量生产环境验证
- ✅ **可扩展** - 支持社交登录、邮箱验证等高级功能
